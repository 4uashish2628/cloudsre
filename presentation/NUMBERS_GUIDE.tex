\section{Before you start}

Open a terminal in the project folder. Every command below is run from here.
\begin{run}
\cmd{cd cloudsre}
\end{run}

All numbers on the slides were produced by \textbf{one existing program}, \texttt{experiments/run\_all.py}. It runs the 8 experiments (E1--E8) and saves their results in the \texttt{results/} folder. The commands in this guide read those result files, so their output matches the slides exactly. Each block shows the command you type (in bold) and the output it prints.

\textbf{If the professor wants the numbers recomputed from scratch}, run the experiments first (about 1 minute), then use the same commands:
\begin{run}
\cmd{.venv/bin/python experiments/run_all.py}
\end{run}
After a re-run, all \emph{accuracy} numbers (detection, false alerts, recall, leakage, tamper detection) come out \textbf{exactly the same}. Only \emph{speed} numbers (entries/s, $\mu$s, seconds) change by about 10--20\%, because they depend on how busy the laptop is. To go back to the exact values used on the slides afterwards:
\begin{run}
\cmd{git checkout -- results paper/figures}
\end{run}
