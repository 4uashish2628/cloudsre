\section{1. The three ways to prove a number}

Run every command from the \texttt{cloudsre} folder.

\begin{tabularx}{\textwidth}{@{}P{3.6cm}LP{2.2cm}@{}}
\toprule
\textbf{Level} & \textbf{What it does} & \textbf{Time} \\
\midrule
\textbf{A. Instant lookup} & Prints every number on the slides, what it means and which result it comes from. Reads the saved results file \texttt{results/summary.json}. & under 1 s \\
\textbf{B. Recompute one slide} & Re-runs that slide's experiment right now, with exactly the same code as the paper, and prints fresh numbers. Writes to a temporary folder, so saved results are not changed. & 10--25 s \\
\textbf{C. Full reproduction} & Re-runs all 8 experiments, regenerates every results file and every figure in the paper. & about 1 min \\
\bottomrule
\end{tabularx}

\begin{cmd}
A:  .venv/bin/python experiments/show_numbers.py            (all slides)
    .venv/bin/python experiments/show_numbers.py 10         (one slide)
B:  .venv/bin/python experiments/show_numbers.py 10 --live
C:  .venv/bin/python experiments/run_all.py
\end{cmd}

\textbf{Important to say if numbers differ slightly.} All \emph{accuracy} numbers (detection rates, false alerts, recall, leakage, tamper detection) are produced by seeded experiments and come out \textbf{exactly the same} every run. Only \emph{speed} numbers (entries per second, microseconds, seconds) vary by roughly 10--20\%, because they depend on what else the laptop is doing. In a test run, ``7.2$\times$'' came out as 7.4$\times$ and ``8\,$\mu$s'' as 6\,$\mu$s. The conclusions do not change.

\section{4. If the professor asks \ldots}

\begin{description}[leftmargin=0pt,itemsep=4pt]
\item[``Show me this number is real.''] Run level A for that slide and point at the \emph{source} line. If they want more, run level B (\texttt{-{}-live}) and show the same value being recomputed.
\item[``Is this data made up?''] It is generated by our seeded simulator (\texttt{cloudforensix/simulator.py}), because real cloud providers cannot be instrumented; the base survey says the same. Show \texttt{python -m cloudforensix.cli simulate -{}-out data}, which writes the raw logs and the hidden ground truth.
\item[``Why is the number slightly different now?''] Only speed numbers vary with machine load; accuracy numbers are seeded and identical every run.
\item[``Where is the code for X?''] Detection: \texttt{detector.py}. Secure log: \texttt{seclog.py}. Correlation: \texttt{correlation.py}. Time correction: \texttt{normalizer.py}. Isolation: \texttt{isolation.py}. Metrics: \texttt{metrics.py}.
\item[``Reproduce everything.''] \texttt{.venv/bin/python experiments/run\_all.py} (about 1 minute) regenerates all results and all paper figures.
\end{description}
